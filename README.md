# Sistema de Gerenciamento Espacial (Prática com TypeScript)

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais do TypeScript através de uma aplicação simples de terminal que simula o gerenciamento de pilotos e naves espaciais.

## 📚 Objetivo

Praticar os estudos de TypeScript, aplicando conceitos como:

- Tipagem estática
- Modularização
- Organização por camadas (controllers e services)
- Uso de estruturas condicionais e loops

## 🚀 Funcionalidades

O sistema permite realizar as seguintes operações:

- Registrar novos pilotos
- Registrar novas naves espaciais
- Adicionar membros à tripulação de uma nave
- Adicionar um piloto a uma nave
- Enviar uma nave para uma missão
- Listar pilotos registrados
- Listar naves registradas
